# Examples

| Example | What it shows |
|---|---|
| [skills/friday-wrap-up](skills/friday-wrap-up/SKILL.md) | A routine of your own: the week's numbers, up to three clients to check on, and a drafted note for each that you approve before anything is sent. [How to install and change it](../docs/skills.md#write-a-routine-of-your-own) |
| [python/weekly_numbers.py](python/weekly_numbers.py) | Your own code: connect with an API key, list the tools, read your roster and this week's numbers. Read-only, standard library only. [How it connects](../docs/connect.md#your-own-code) |

Both use your Agents4 Fitness coach account on the Architect plan. The Python example needs an API key from the
Agents4 Fitness app (More → Connect ChatGPT & Claude → Generate API Key).
